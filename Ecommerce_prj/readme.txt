# E-Commerce Executive Performance & Logistics Dashboard

An executive-level Power BI reporting solution monitoring GMV trajectory, RFM customer cohorts, and fulfillment SLA performance.

## Dashboard Preview
![Dashboard Preview](dashboard_preview.png)

## Key Business Metrics
-Total Revenue (GMV): $15.42M
-Delivered Orders:96K
-Average Order Spend:$165.20

## Core Analytical Components
1. Executive KPI Strip: Macro-level performance metrics tracking top-line volume and order economics.
2. Monthly GMV & MoM Trend: Combo chart evaluating sales trajectory and monthly growth rates across multi-year cycles.
3. RFM Customer Segmentation: Cohort distribution highlighting Champions/VIPs, At-Risk, and Churned segments.
4. Logistics SLA Bottlenecks: Horizontal bar chart isolating regional delivery performance and highlighting states with late delivery rates exceeding 20%.

## Tech Stack
- Business Intelligence: Power BI Desktop (DAX, Data Modeling, Custom UI/UX)
- Data Engineering: SQL / Power Query
- Data Source: E-Commerce Transaction & Fulfillment Data

## How to View
1. Clone or download this repository.
2. Open the '.pbix' file using [Power BI Desktop](https://powerbi.microsoft.com/desktop/).
